# Nova Design System Skill

Use existing Nova visual tokens and components before creating new ones.

Check:
- Typography
- Spacing
- Colors
- Buttons
- Inputs
- Cards
- Navigation
- Tables
- Modals
- Feedback states
- Responsive breakpoints

Maintain consistency across customer, seller, admin, and operational interfaces.
