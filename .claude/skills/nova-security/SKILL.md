# Nova Security Skill

Apply security by default.

Check:
- Authentication
- Authorization
- Input validation
- Output encoding
- Secrets
- Dependencies
- Rate limits
- CSRF/XSS/SQL injection risks
- Access control
- Sensitive logging
- Payment boundaries
- Webhook verification

Never expose secrets in code, logs, commits, or generated documentation.
