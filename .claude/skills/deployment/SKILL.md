# Nova Deployment Skill

Deployment workflow:
1. Inspect current CI/CD.
2. Validate build.
3. Validate environment configuration.
4. Run relevant tests.
5. Check migrations.
6. Check observability.
7. Deploy through the established pipeline.
8. Verify health and critical flows.
9. Keep rollback available.
