# Nova Testing Skill

Prioritize tests around business-critical behavior.

Minimum focus:
- Authentication
- Product/catalog
- Cart
- Checkout
- Payment
- Orders
- Inventory
- Seller/admin permissions

Use the repository's existing test framework. Do not introduce a new framework unless justified.
