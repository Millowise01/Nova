# Nova Architecture Skill

Use this skill for architecture decisions and cross-domain changes.

Workflow:
1. Inspect the repository.
2. Identify current architecture and boundaries.
3. Identify affected domains.
4. Reuse existing patterns.
5. Propose the smallest sound design.
6. Identify security, performance, reliability, and migration risks.
7. Implement only after the design is coherent.
8. Record significant decisions as ADRs when appropriate.
