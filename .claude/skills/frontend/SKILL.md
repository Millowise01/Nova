# Nova Frontend Skill

Before UI changes:
1. Inspect existing components.
2. Identify reusable primitives.
3. Follow the existing design system.
4. Preserve responsive behavior.
5. Handle loading, error, empty, and success states.
6. Check accessibility.
7. Avoid duplicate components.
